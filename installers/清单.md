## 依赖与插件

- `dependencies/PowerShell/` 包含本机的 `onehalf.minimal.omp.json`、`posh-vcpkg` 模块、vcpkg 程序和对应源码归档，以及本机安装的 Meslo Powerline 字体。`posh-git` 1.1.0 和 `PSReadLine` 2.4.5 使用 PowerShell Gallery 的原始 `.nupkg`。PowerShell 7.7.0 已自带 PSReadLine 2.4.5。 [posh-git](https://www.powershellgallery.com/packages/posh-git/1.1.0) · [PSReadLine](https://www.powershellgallery.com/packages/PSReadLine/2.4.5)
- `dependencies/Windows/` 包含 .NET 10 Desktop Runtime 10.0.15、Visual C++ v14 x64 Redistributable 14.52.37029.0 和 WebView2 Evergreen x64 独立运行时。Clash Verge Rev 安装包内还附有固定版 WebView2 和内核。 [mpv.net 运行时要求](https://github.com/mpvnet-player/mpv.net/releases/tag/v7.1.2.0) · [Visual C++ 运行时](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist) · [WebView2 独立运行时](https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution)
- `dependencies/Wireshark/` 提供单独的 Npcap 1.90 驱动安装包。Wireshark 的 EXE 也内置 Npcap。 [Npcap 下载](https://npcap.com/#download) · [Wireshark 安装说明](https://www.wireshark.org/docs/wsug_html_chunked/ChBuildInstallWinInstall.html)
- `dependencies/FluxDown/` 提供 0.6.9 对应的 Chromium 解压扩展、Firefox 扩展，以及 YouTube 解析插件 2.0.2。 [FluxDown 0.6.9 发布](https://github.com/zerx-lab/FluxDown/releases/tag/v0.6.9) · [FluxDown 插件索引](https://github.com/zerx-lab/fluxdown-plugin-index)
- `dependencies/ChatGPT/` 提供 OpenAI 官方 x64 离线包 `ChatGPT.msix`，包版本为 26.1120.6357.0，并附 `ChatGPT-License.xml`。离线安装需管理员权限，使用 ChatGPT 需联网。 [OpenAI Windows 离线部署](https://learn.chatgpt.com/docs/enterprise/windows-deployment#install-from-an-offline-package)
- `dependencies/ImageJ/ij.jar` 是 ImageJ 最新稳定核心 1.54t。解压 Windows 整包后，用它替换 `ImageJ/ij.jar` 即可离线更新。 [ImageJ 官方更新说明](https://imagej.net/ij/upgrade/index.html)
- `dependencies/Bitwarden/` 包含同版本的浏览器解压扩展。 `dependencies/QuickView/` 包含同版本的 NCNN Vulkan 超分辨率插件。 [Bitwarden 浏览器扩展发布](https://github.com/bitwarden/clients/releases/tag/browser-v2026.11.0) · [QuickView 发布](https://github.com/justnullname/QuickView/releases/tag/v6.59.2.1)
- `dependencies/pinyin-gloss/LLM/` 包含默认的 LMT-60-1.7B Q4_K_M 模型、许可证和 llama.cpp b11077 的 CPU 与 CUDA 运行时归档。需复用本地模型时，把整个 `LLM` 目录复制到解压后的主程序同级目录，运行应用自带的 `Setup-LLM.cmd` 并选择 Q4_K_M。 [模型来源](https://huggingface.co/mradermacher/LMT-60-1.7B-GGUF) · [llama.cpp b11077](https://github.com/ggml-org/llama.cpp/releases/tag/b11077)
